# Converter-corpus cases an ENGINE is known to diverge on.
#
# `npm run compare:impls -- --corpus=convert` converts every case in
# tests/corpus-convert/ with each engine that implements the source format,
# renders every produced document through carve-js, and compares that render
# against the case's expected.html. A mismatch is not automatically wrong:
# when a converter rule is pinned here before an engine ships it, the corpus
# is ahead of that engine until its fix lands. That window is normal, and -
# exactly as with resources/engine-pin-drift.txt - it is DECLARED rather than
# tolerated.
#
# The runner fails (under --fail-on-diff) when the real set differs in EITHER
# direction:
#
#   - an (engine, case) pair mismatches and is not listed  -> new converter
#     drift, or a wrong expectation. Red immediately, which is the point.
#   - a pair is listed and now matches  -> the engine fix landed. Delete the
#     line in the same commit that proves it.
#
# Engine names are the runner's: rust, js, php. An engine with NO importer for
# a format does not belong here - that is a declared capability gap, and it
# lives in scripts/lib/converter-formats.mjs instead.
#
# Format: <engine>/<case-slug><space><space><reason>
