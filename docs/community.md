# Community

## Ask a question

- [GitHub Discussions](https://github.com/markup-carve/carve/discussions) keeps answers searchable.
- [The Carve Discord](https://discord.gg/ENgwFBdUZV) is for conversation and work in progress.

## Report a 0.2 finding

Search the [language issues](https://github.com/markup-carve/carve/issues) first. For a specification question or a difference between engines, include the input, the expected and actual results, the spec commit, and the `C2-` clause you read. The [conformance corpus](./conformance) explains case IDs. For a bug confined to one implementation, use that implementation's issue tracker; the [ecosystem page](./ecosystem) links the projects.

The 0.2 text is a freeze candidate on `next2`. State whether the finding is against that branch or a released 0.1 engine. The two versions have different syntax and clause IDs.

## Contribute

The [development page](./development) covers the spec repository and its checks. [Implementing Carve](./implementing-carve) is a starting point for another engine. [Releases](https://github.com/markup-carve/carve/releases) cover published versions; [the 0.2 status](https://github.com/markup-carve/carve/blob/next2/spec/0.2/STATUS.md) covers the candidate.
