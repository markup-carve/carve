# Community

## Ask a question

- [The markup-carve Discord](https://discord.gg/ENgwFBdUZV) - chat with other
  people using Carve. Best for a quick question or showing something you are
  working on.
- [GitHub Discussions](https://github.com/markup-carve/carve/discussions) - for
  questions worth keeping. Searchable, and an answer here helps the next person
  who asks.

## Report something

- [Issues on the language repo](https://github.com/markup-carve/carve/issues) -
  for a syntax question, a spec ambiguity, or behavior that disagrees across
  implementations.
- Issues on the specific repo - for a bug in one engine, editor plugin or
  integration. The [ecosystem page](/ecosystem) lists every repo and what it
  does.

A rendering bug is worth reporting even when you are not sure which layer owns
it. A document that three engines disagree about is a finding in itself.

## Follow along

- [r/markup_carve](https://www.reddit.com/r/markup_carve) - news, questions, and
  what people have built.
- [Releases](https://github.com/markup-carve/carve/releases) - what changed, per
  version.

## Contribute

The [development guide](/development) covers the repository layout and how to
run the test corpus. [Implement Carve](/implementing-carve) is the starting
point for a new engine or editor integration, and
[awesome-carve](https://github.com/markup-carve/awesome-carve) collects what
already exists.
