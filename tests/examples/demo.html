    return f"Hello, {name}!"

key: value

Math

Inline math uses a dollar before a code span: \(e = mc^2\).

Display math uses a double dollar:

\[e^{i\pi} + 1 = 0\]

A fenced math block is the GFM-style block form (mathBlock extension):

\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
